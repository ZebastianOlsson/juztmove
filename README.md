# JuztMove

Träningsapp för vardagsrörelse, styrka, löpning och rörlighet – https://zebastianolsson.github.io/juztmove/

- Databas och inloggning: Supabase (`supabase/schema.sql`).
- Se `CLAUDE.md` för hur appen utvecklas och vilka regler som gäller.
